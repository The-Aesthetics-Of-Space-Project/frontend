# 공간의 미학(The-Aesthetics-Of-Space-Project)

## ❓ 프로젝트 소개
- 본 프로젝트는 인테리어에 관심 있는 사람들이 서로 소통하고 아이디어를 공유할 수 있는 커뮤니티 웹사이트를 개발하는 것을 목표로 한다.
- 사용자들이 자유롭게 의견을 나누고, 서로의 인테리어 디자인을 공유함으로써, 개인의 취향과 필요에 맞는 독특하고 매력적인 인테리어 공간을 창조할 수 있도록 돕는다.
- 이 과정을 통해, 각자의 생활 공간을 더욱 개성 있고 기능적으로 꾸밀 수 있는 영감을 제공하고자 한다.
- 또한, 이 커뮤니티는 사용자들의 삶의 질을 향상하고, 인테리어 분야에서의 혁신을 끌어내는 플랫폼이 되고자 한다.

## 🛠 기술 스택 
| 이름               | 분류                                       |
|--------------------|-------------------------------------------|
| **Bootstrap**      | CSS 프레임워크 (UI 프레임워크)             |
| **Socket.IO**      | 실시간 통신 라이브러리                     |
